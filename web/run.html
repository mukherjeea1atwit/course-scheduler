Two engines, two separate schedules. They read the same input files but write different output files, so you can start one and keep using the other's results — including while it is still solving.

Greedy scheduler instant

The original engine. Places sections one at a time in priority order and finishes in well under a second. Writes schedule.json / schedule.csv.

CP-SAT scheduler typically tens of seconds

Solves the whole timetable at once with a constraint solver, which usually finds fewer unplaced sections than the greedy engine. Expect tens of seconds, and occasionally a couple of minutes — solve time varies substantially from run to run, and the maximum is 8 minutes, after which the best schedule found so far is used. That variation is deliberate: the engine is not seeded, so re-running it gives you a different valid timetable to choose between. Writes schedule_cpsat.json / schedule_cpsat.csv, so it never touches the greedy engine's output — you can keep reading and exporting the greedy schedule while this one solves.
